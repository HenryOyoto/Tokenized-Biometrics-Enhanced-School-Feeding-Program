# Tokenized Biometrics-Enhanced School Feeding Program

A two-node ESP32 system that ties each learner's meal to a fingerprint token, verified at the serving point and settled through M-Pesa.

## Overview

This project explores an embedded and IoT-based approach to managing school feeding transactions.

A learner is identified through a biometric token, the meal transaction is verified at the serving point, and the resulting feeding record is processed as part of a digital payment and monitoring workflow.

## Key Areas

- ESP32 embedded systems
- Fingerprint identification
- Tokenized learner identification
- Serving-point verification
- Feeding transaction records
- Wireless communication
- M-Pesa payment integration
- Digital monitoring

## System Structure

The project is organized around two embedded nodes that communicate as part of the feeding and transaction workflow.
